# Changelog

## 1.0.0 – 2026-11-10

First public release.

- ESPHome package for ESP8266 (D1 mini) and ESP32 with example device files
- Word clock with West and East dialect, analog clock with hands and seconds dot
- Color sets that drift slowly through every word or hand
- Timer with three styles (letters, ring, pie), blinking at zero and Home Assistant entities
- Notification animations: door, doorbell, 3D printer, washer, mail, done, warning
- Night mode, smooth cross-fades, LED current limit
- Time from Home Assistant and SNTP, optional DS3231 RTC detected at boot
- Home Assistant blueprints: timer helpers, Alexa timers, Assist voice timer, notification animation
- Host tests and README images rendered from the real frames
